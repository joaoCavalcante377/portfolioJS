# Portfolio JS

## Pré-requisitos

- [Node.js](https://nodejs.org/) instalado

## Instalação

```bash
npm install
```

## Rodando o projeto

### Front-end 

```bash
npm run dev
```

Acesse: `http://localhost:5173`

---

### Back-end

```bash
npm run server
```

---
### Modo de Administrador

Acesse: `http://localhost:5173/portfolioJS/?admin=DW2ADM`
